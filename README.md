# Two-Player Rock, Paper, Scissors in Dart

## How to Run

1. Make sure Dart is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
dart run
```

5. Enter the names and choices of the two players.
6. The program will display the winner or draw.

## Requirements

* Dart SDK
* Visual Studio Code
